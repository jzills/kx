A patch that makes kx's errors read as one voice, and lets `kx theme` and `kx engine` repair a config value kx doesn't recognize.

- **One shape for errors:** Each error names the problem, then the fix after a dash, as in `'app' and 'pod-template-hash' are already set — add '--overwrite' to replace them` from `kx label`.
- **A config you can repair:** An unknown `theme` or `engine` in `~/.kx/config.toml` no longer stops `kx theme` and `kx engine`, so `kx theme dracula` fixes the file.
- **Help for every subcommand:** The help for `kx top --sort-by` and `--show-swap`, and for `kx rollout --revision`, now describes every subcommand that takes them.
- **Security:** The binaries are built with Go 1.26.10, for GO-2026-6809.
