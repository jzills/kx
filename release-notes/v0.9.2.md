A patch for the words kx uses, in its errors and its help, and for a config mistake it gave you no way out of.

- **One shape for errors:** Each error now names the problem, then the fix after a dash, as in `'app' and 'pod-template-hash' are already set — add '--overwrite' to replace them` from `kx label`.
- **A config you can repair:** An unknown `theme` or `engine` in `~/.kx/config.toml` no longer stops the two commands that set them, so `kx theme dracula` fixes the file.
- **Help for every subcommand:** The help for `--sort-by` and `--show-swap` on `kx top`, and for `--revision` on `kx rollout`, now covers every subcommand that takes them.
- **Security:** The binaries are built with Go 1.26.10, for GO-2026-6809.
