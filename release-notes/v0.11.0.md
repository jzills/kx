A release that finishes `--sort`, adds `kx taint`, and gives an agent more of kx to read.

- **Sorting events and watches:** The `--sort` flag now orders `kx events` and the live table `kx get --watch` draws.
- **Completion for sort keys:** Pressing TAB after `--sort` offers the columns kx last printed for that kind, so `--sort status,-re<TAB>` completes to `status,-restarts`.
- **Tainting Nodes:** Running `kx taint 1 dedicated=gpu:NoSchedule` sets a taint, and a `NoExecute` taint asks first unless you pass `--yes`.
- **More for agents:** The MCP server gained `describe` and `rollout_history` tools, and its listing tools take a `sort`, all still read-only.
- **Marks in copies:** Either side of `kx cp` can name its Pod by mark, as in `kx cp @api:/etc/config.yaml ./config.yaml`.
- **A new site:** The site was rebuilt around a landing page, with a light/dark button and a page that lists every release.

A script that runs `kx describe <index>` on a deleted resource now gets exit 1 and a fresh listing, where it used to get exit 0 and kubectl's description of every resource the name was a prefix of.
