A release that rounds out sorting, adds a command for Node taints, and gives an agent more of kx to read.

- **Sorting events and watches:** Events and the live table `kx get --watch` draws now take `--sort` too.
- **Completion for sort keys:** Pressing TAB after `--sort` offers the columns kx last printed for that kind, so `--sort status,-re<TAB>` completes to `status,-restarts`.
- **Tainting Nodes:** A new command sets a taint, as in `kx taint 1 dedicated=gpu:NoSchedule`, and asks first before a `NoExecute` one unless you pass `--yes`.
- **More for agents:** The MCP server gained `describe` and `rollout_history` tools, and its listing tools take a `sort`, all still read-only.
- **Marks in copies:** Either side of `kx cp` can name its Pod by mark, as in `kx cp @api:/etc/config.yaml ./config.yaml`.

**Breaking:** If a script runs `kx describe <index>` on a deleted resource, expect exit 1 and a fresh listing: it used to exit 0 and describe every resource whose name started with the one you asked for.
