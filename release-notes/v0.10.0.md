Listings can now be put in the order you care about before kx numbers them, so the row you want is row 1.

- **Sort by columns:** With `kx get pods --sort -restarts,age`, the worst-restarting Pod comes first, and each column sorts as what it holds, AGE as a duration and READY as a ratio.
- **Every table kx draws:** Sorting works on `kx get`, `kx top`, `kx secret`, `kx scan` and a `kx diag` sweep, and `kx top --sort -mem%` orders by a column kubectl's own `--sort-by` lacks.
- **Refresh lines you can paste:** When the resource behind an index is gone and a program is reading the output, the line kx prints now keeps the listing's flags, as in `Run 'kx get pods -n diagnostics --output=wide --sort="nominated node" -m web' to refresh the list`.
- **Kinds as types:** Findings name kinds as types, as in `CrashLoopBackOff in Pod cache-oom-cc849dbdb-2qdkw`.

**Breaking:** If a script passes `kx diag --full`, change it to `--show-healthy`; `kx scan --full` keeps its name. If it parses a sweep's findings or `kx top nodes`, check it: kinds are spelled as types, and the memory column is always MEM%.
