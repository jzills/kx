A release about order: the listings kx draws can now be sorted by their own columns before they are numbered, so row 1 is the first sorted row.

- **Sort by columns:** Running `kx get pods --sort -restarts,age` puts the worst-restarting Pod at 1, with each column sorted as what it holds, AGE as a duration and READY as a ratio.
- **Everywhere a table is:** The `--sort` flag works on `kx get`, `kx top`, `kx secret`, `kx scan` and a `kx diag` sweep, and `kx top --sort -mem%` orders by a column kubectl's own `--sort-by` lacks.
- **Hints you can paste:** A stale index's relist hint now names the shape its listing was taken in and quotes its values, so pasting it back returns the same table.
- **Kinds as types:** Findings and messages write kinds as types, as in `CrashLoopBackOff in Pod cache-oom-cc849dbdb-2qdkw`.

If a script passes `kx diag --full`, change it to `--show-healthy`; `kx scan --full` keeps its name. A script that parses a sweep's findings or `kx top nodes` may need updating too: kinds are spelled as types, and the memory column is always MEM%.
