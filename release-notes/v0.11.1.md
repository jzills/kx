A patch for the completion of a sort key written the way kx's own help writes it.

Pressing TAB in `kx get pods --sort -re<TAB>` completed nothing. Cobra decides whether it is completing a flag's value before it parses the line, and reads any word opening with a dash as the start of a flag name, so `--sort` was left without its value and the line was refused before kx ever saw it; the shell was left to match filenames, which a sort key never looks like. The attached spelling, `--sort=-re`, had always worked. Descending is the order the help leads with — `kx top --sort -mem%,-cpu%` — so the form most likely to be typed was the one that answered least.

A descending key now completes on `kx get`, `kx top`, `kx events`, `kx diag` and `kx scan` alike, and so does the value of any other flag that begins with a dash.

Upgrading asks nothing of you. Only what the shell offers has changed: every command runs as it did, and a `~/.kx/state.json` written by 0.11.0 resolves the same indexes.
