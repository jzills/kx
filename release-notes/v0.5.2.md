A patch that finishes shell completion and sharpens the documentation around `--since` windows.

- **No more filename guesses:** Pressing TAB after `--fail-on` now offers its values, where it used to list files, the last flag in kx that did.
- **Install steps per shell:** The completion install examples now say which shell each one is for.

**After upgrading:** If you installed completions before this release, reinstall them: under zsh, the old steps left the bash script shadowing the zsh one.
