Sharpens shell completion and the documentation around `--since` windows. No command changes behaviour, so upgrading is safe from any 0.5.x.

`--fail-on` now offers its own values at the prompt, which is the last flag in kx that fell through to filename completion. If you installed completions before this release, reinstall them — the install examples now say which shell each one is for, and following them in order under zsh left the bash script shadowing the zsh one.
