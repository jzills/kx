A patch for shell completion and the documentation around `--since` windows.

- **Completion for every flag:** The `--fail-on` flag now offers its own values at the prompt, the last flag in kx that fell through to filename completion.
- **Install steps per shell:** The completion install examples now say which shell each one is for.

If you installed completions before this release, reinstall them: under zsh, following the old examples in order left the bash script shadowing the zsh one.
