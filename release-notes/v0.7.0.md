The headline is `kx mcp`, a Model Context Protocol server that lets an agent read your cluster the way you do: by kind and name, by a mark, or by an index from your current listing. Every one of its ten tools is read-only against the cluster.

- **One-line setup:** Adding it to Claude Code takes one command, `claude mcp add kx -- kx mcp`.
- **Shared listings, if you want them:** Started with `--write-listings`, the agent's listings join your history tagged as the agent's, and a command that changes something warns before it spends one of their indexes.
- **Job logs:** The `kx logs` command now aggregates a Job's Pods, retries included.
- **More forwarded flags:** The `kx label` and `kx annotate` commands forward kubectl's own flags, so `--dry-run` works there too.
- **A stable download URL:** Every release attaches its archives under version-free names, so `https://github.com/jzills/kx/releases/latest/download/kx_linux_amd64.tar.gz` always fetches the newest build.
