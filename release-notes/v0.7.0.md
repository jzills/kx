An agent can now read your cluster through kx the way you do: by kind and name, by a mark, or by an index from your current listing.

- **An MCP server:** The new `kx mcp` command serves ten tools for listing, diagnosis, events, logs and scans, every one read-only against the cluster.
- **Setup:** Any MCP client starts it as `kx mcp`, and Claude Code adds it with `claude mcp add kx -- kx mcp`.
- **Shared listings, if you want them:** With `--write-listings`, what the agent lists joins your history, numbered and tagged as the agent's, and a command that changes something warns before acting on one of its rows.
- **Job logs:** Reading a Job with `kx logs` now covers all of its Pods, retries included.
- **A stable download URL:** Every release now attaches its archives under version-free names, so `https://github.com/jzills/kx/releases/latest/download/kx_linux_amd64.tar.gz` always fetches the newest build.
