Two new commands spend an index where you used to copy a name out of a listing, and `kx get all` is now indexable. This release also fixes five HTTP/2 advisories reachable through client-go.

- **Waiting on a resource:** The `kx wait` command blocks until each indexed resource reaches its condition, and a failed Job ends the wait with its reason rather than running to the timeout.
- **Changing images:** The `kx set image` command changes an indexed workload's images and prints each one before and after.
- **Narrower sweeps:** The `--match` term now narrows `kx diag`, `kx scan` and `kx tree` sweeps as well as listings.
- **State for scripts:** Running `kx state --json` prints what each index currently means, with the query and provenance behind it.
- **An install script:** Running `curl -fsSL https://jzills.github.io/kx/install.sh | sh` installs the newest build for Linux or macOS, checked against SHA256SUMS.

If a script passes `-m` beside JSON, YAML, a template or `--no-headers`, expect exit 1: kx refuses a match term it can't apply rather than printing everything. Building from source now needs Go 1.26.9, which the published binaries already carry.
