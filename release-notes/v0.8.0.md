Two new commands work from a listing's indexes instead of a name you copy out of it, and this release closes five HTTP/2 advisories reachable through client-go.

- **Waiting on a resource:** The `kx wait` command blocks until each numbered resource is ready, bound or complete, and a failed Job ends the wait with its reason instead of the timeout.
- **Changing images:** Each image `kx set image` changes is printed before and after, so you can see what to put back.
- **Narrower sweeps:** Health checks, scans and trees now take `--match` too, as in `kx diag -m api`.
- **State for scripts:** A script can read what each index means from `kx state --json` instead of parsing the table.
- **An install script:** One line installs the newest build for Linux or macOS, checked against the release's checksums: `curl -fsSL https://jzills.github.io/kx/install.sh | sh`.

**Breaking:** If a script passes `-m` beside JSON, YAML, a template or `--no-headers`, expect exit 1: kx now refuses a match it can't apply instead of printing everything. If you build from source, you need Go 1.26.9, which the published binaries already carry.
