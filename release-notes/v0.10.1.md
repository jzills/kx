A release about getting straight to the rows you came for, with fewer commands in between.

- **Limit before numbering:** With `kx get pods -A --sort age --limit 5`, the five newest Pods are rows 1 to 5, and an index past them names nothing.
- **Latest CronJob runs:** Each CronJob's newest Job is one row in `kx get jobs --last-run`, so `kx logs 1` reads that run.
- **Docs in the binary:** Documentation pages now read offline with `kx docs <topic>`, and a `docs` tool on `kx mcp` answers an agent from the same pages.
- **Completion for krew in zsh:** Tab completion now works for a krew install run as `kubectl idx` under zsh.

**After upgrading:** If you installed through krew and use zsh, run `ln -s ~/.krew/bin/kubectl-idx ~/.krew/bin/kubectl_complete-idx` to turn that completion on.
