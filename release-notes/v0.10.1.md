A release about getting to the rows you came for: the first few of a sorted listing, or the latest run of each CronJob, numbered so the next command is one index away.

- **Limit before numbering:** Running `kx get pods -A --sort age --limit 5` numbers the five newest Pods 1 to 5, and an index past them names nothing.
- **Latest CronJob runs:** Running `kx get jobs --last-run` lists the newest Job each CronJob created, so `kx logs 1` reads that run.
- **Docs in the binary:** Running `kx docs <topic>` reads a documentation page in the terminal, offline, and a new `docs` tool on `kx mcp` answers an agent from the same pages.
- **Completion for krew in zsh:** Tab completion now works when kx is installed through krew and run as `kubectl idx` under zsh.

If you installed through krew and use zsh, run `ln -s ~/.krew/bin/kubectl-idx ~/.krew/bin/kubectl_complete-idx` to turn that completion on.
