{{- /* The two typefaces every project docs site is set in, Inter and JetBrains Mono. Shared, byte for byte, by kx, snoop, action-cache and hmac-manager: change it in one, copy it to all four, with assets/vendor/inter/ and assets/vendor/jetbrains-mono/ beside it. Vendored rather than fetched from Google Fonts: a page that renders from its own origin, and a build that needs no CDN. Variable fonts, Latin subset, so each face is one file of about 45 KB for every weight. Declared here rather than in a stylesheet because the URLs come from Hugo's pipeline, fingerprinted, and custom.css is compiled by the theme's Tailwind build, which can't call resources.Get. Preloaded, since headings are set in Inter and would otherwise paint once in the fallback first. The faces reach the page through assets/css/oss-chrome.css, which points Hextra's --hx-default-font-family and --hx-default-mono-font-family at them. */ -}} {{- $fonts := slice (dict "family" "Inter" "path" "vendor/inter/inter-latin-wght-normal.woff2" "weight" "100 900") (dict "family" "JetBrains Mono" "path" "vendor/jetbrains-mono/jetbrains-mono-latin-wght-normal.woff2" "weight" "100 800") -}} {{- range $fonts }} {{- with resources.Get .path }} {{- $font := . | fingerprint }} {{- end }} {{- end }}
